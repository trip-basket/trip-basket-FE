# UI-데이터 매핑 명세

각 UI 영역에 표시할 데이터와 액션을 정의한다.

---

## 1. 캘린더 헤더

| 데이터 | 설명 |
|--------|------|
| room.name | 여행 이름 (수정 가능) |
| calendarStore.tripDays (첫/마지막 date) | 여행 기간 |
| room.currency | 통화 단위 |
| members[].profileImageUrl | 참여자 아바타 (최대 5 + "+N") |
| 총 비용 합산 | 전체 블록 cost 합계 |

**액션:** 여행 이름 수정, 초대 코드 공유, 멤버 관리, (방 TODO — 위치 미확정)

---

## 2. 날짜 헤더

| 데이터 | 설명 |
|--------|------|
| dayOfWeek | 요일 |
| date | 날짜 |
| 해당 일자 비용 합계 | 그 날짜 블록들 cost 합산 |

---

## 3. 캘린더 블록

| 데이터 | 설명 |
|--------|------|
| name | 표시명 (기본: placeName, 유저 수정 가능) |
| startTime ~ endTime | 시간 범위 |
| cost | 비용 |
| reactions.length | 좋아요 개수 |
| category / color | 카테고리별 색상 (관광/식사/쇼핑/이동 등) |
| lockedBy | 다른 유저 편집 중 → opacity 낮춤 |

**액션:** 드래그 이동, 리사이즈, 클릭 → 블록 상세 사이드 패널

---

## 4. Bucket 카드

버킷 = 캘린더 블록에서 날짜/시간만 빠진 상태

| 데이터 | 설명 |
|--------|------|
| name | 장소명 |
| category 아이콘 | 관광/식사/쇼핑 등 |
| cost | 예상 비용 |
| addedBy 아바타 | 누가 추가했는지 |
| lockedBy | 다른 유저가 캘린더로 옮기는 중 → opacity 낮춤 |

**액션:** 캘린더로 드래그, 삭제

---

## 5. 지도 패널

| 데이터 | 설명 |
|--------|------|
| 검색 입력값 | 자동완성 |
| 캘린더 블록 마커 | 현재 날짜 블록들의 위치 |
| 버킷 아이템 마커 | 버킷 장소들의 위치 (다른 색상) |
| 선택된 장소 마커 | 현재 선택 장소 강조 |

**액션:** 장소 검색, 지도/마커 클릭 → 장소 상세 바텀시트

---

## 6. 장소 상세 바텀시트

지도에서 장소 클릭 시 하단에 작은 바텀시트로 표시.

| 데이터 | 출처 |
|--------|------|
| placeName | Google Maps 장소명 |
| formattedAddress | 주소 |
| photos | 대표 사진 |
| rating + reviewCount | 평점 + 리뷰 수 |
| category / types | "관광명소", "레스토랑" 등 |
| openingHours | 운영시간 |
| priceLevel / cost | 예상 비용 |
| phoneNumber | 전화번호 |
| websiteUrl | 웹사이트 |

**액션:**

- **"일정에 추가"** → 날짜/시간 선택 → 캘린더 블록 생성
- **"버킷에 추가"** → 바로 Bucket에 추가

---

## 7. 블록 상세 사이드 패널

캘린더 블록 클릭 시 옆에서 열리는 사이드 패널 (backdrop 포함).

| 섹션 | 데이터 | 설명 |
|------|--------|------|
| **기본** | name | 표시명 (수정 가능) |
| | place.placeName | 원본 장소명 (읽기 전용) |
| | 날짜 + startTime ~ endTime | 일정 시간 (수정 가능) |
| | category | 카테고리 (수정 가능) |
| **장소** | formattedAddress | 주소 |
| | openingHours | 운영시간 — 블록 시간과 안 맞으면 경고 |
| | 미니맵 or "지도에서 보기" | lat/lng 기반 |
| **비용** | cost | 예상 비용 (수정 가능) |
| **설명** | description / memo | 장소에 대한 메모, 자유 텍스트 |
| **블록 TODO** | blockTodos[] | 해당 장소에서 할 일 목록 |
| **소셜** | reactions[] | 좋아요 누른 멤버 아바타 + 토글 버튼 |

**액션:** 각 필드 수정, TODO 추가/완료/삭제, 좋아요 토글, "버킷으로 이동", "삭제"

---

## 미확정 사항

- **방 TODO 위치**: 캘린더 헤더 영역 (아이콘 → 드롭다운/패널) 유력, 미확정
